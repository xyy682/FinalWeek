# 2026-08-23 真实课程资料测试修复说明

> 本文记录一次真实使用后的增量修订；修订后的当前完整行为已经汇总到 [`GPT_CONTEXT.md`](GPT_CONTEXT.md)。

本轮改动来自数据库课程资料的真实手工测试，覆盖 FW-001～FW-007。问题详情、运行证据和面试复盘见仓库外的持续记录 `D:\学习项目\finalweek的问题与修复\FinalWeek问题与修复记录.md`。

## 上传与后台处理

- 上传面板支持一次选择或拖入最多 50 个文件，一批文件共用资料类型和重点说明。
- 浏览器最多并行处理 3 个文件，每个文件内部仍按原协议顺序分片；列表展示单文件和整批进度，可移除待上传项、清除完成项、仅重试失败项。
- 分片是上传可靠性机制，不等于内容解析分段。文档、PPTX、音视频继续共用断点上传协议。
- RabbitMQ 发布保护默认从用户/全局每分钟 `5/30` 调整为 `30/120`；consumer 默认并发 `2`、最大 `4`、prefetch `1`。上传完成的数据不会因发布限流被回滚。

## PPTX

PPTX 使用 `OPCPackage.open(file, PackageAccess.READ)` 的只读随机访问模式打开，避免合法高压缩媒体被流式读取路径误判。解析日志保留 task、material、文件名、大小及原始异常；安全拒绝与无效包使用不同错误码和用户提示。未降低 POI 的进程级 ZIP 安全阈值。

## 音视频与 ASR

FFmpeg 只为整份媒体生成一个 16 kHz、单声道 WAV。应用不再按 60 秒切 ASR 片段，也不再用手写的 3.2 KB + 95 ms 实时推送循环；改用百炼 Java SDK 的本地文件非流式调用并读取句级时间戳。上传分片仍保留，ASR 语义分片移除。

当前本地部署不能把 `localhost` MinIO URL 提交给云端异步录音文件转写，所以仍使用支持本地文件的 SDK 调用。若未来对象存储具备受控公网 URL，可再切换真正的异步录音文件转写模型并通过回调/轮询取结果。

## 知识提纲

- 生成上下文按知识版本中的资料分组、均匀采样，避免检索 TopK 让单份课件垄断提纲。
- 真题、题库、教师重点只作为覆盖和重要度信号，不能生成“考试重点与形式说明”等非知识节点。
- 校验器拒绝考试形式、分值、通知、复习建议、资料目录类标题；节点较多时限制单一来源覆盖比例，并允许模型自动修复一次。
- 首版 UI 调整遗漏 Element Plus el-tree 的固定节点高度，双行节点在真实页面中发生纵向重叠；该回归已修复。
- 树节点容器显式使用自动高度，标题、重要度编辑合并在主标题行，来源放在独立次级行；删除来源编号噪声和把下拉框推到卡片最右侧的自动外边距。
- 节点之间增加轻量分隔，来源使用低视觉重量文本按钮；移动端标题独占一行，重要度与来源自然换行。

## 模拟卷

- AUTO 模式不再信任模型返回的分值。后端根据题型默认权重进行确定性整数分配，必要时使用逐题余数分配，保证最终总分严格等于用户目标。
- CUSTOM 模式同样由后端覆盖为用户配置的单题分值；前端不再让用户重复填写可能冲突的总分。
- 模型引用先去重并过滤不属于本次知识版本的 UUID；课程题过滤后必须仍保留至少一个有效来源。
- 抄题检测同时比较题干侧和资料侧覆盖率，避免长题干包裹原题绕过检测。
- 出卷改为按题型拆分批次、最多两路并发生成；格式、来源或原题复刻校验失败时只重试失败题型，不再推倒整卷。只有全部批次通过并合并校验后才写入“已生成试题”断点。
- 单选与多选固定四个选项；非选择题的模型冗余 options 由服务端确定性清空。新增“综合题”，使用案例/材料、关联小问和分点参考答案，默认权重 20 分。

## 课程问答

- 回答正文禁止输出 UUID；服务端保存前再次移除方括号 UUID，前端也兼容清理历史脏数据。
- `SafeMarkdown` 在不使用 `v-html` 的前提下支持标题、无序/有序列表、粗体、斜体、行内代码、代码块和安全 HTTP(S) 链接。
- 来源单独显示为 `[1] 第 N 页/张/时间点`，点击后在来源抽屉展示文件名和原文；通用知识区明确提示其不是课程资料原文。

## 模拟卷试卷 PDF 排版

- 修复试卷端仅使用源码换行和未结束段落的 `\vspace`，导致 XeLaTeX 把多道客观题合并为连续文本的问题；参考答案模板保持不变。
- 每个题型使用独立编号列表，每道题是独立 `\item`；题干使用固定正文宽度，分值使用固定宽度栏右对齐，长题干不再把分值挤入下一行或下一题。
- 选择题选项使用嵌套列表；客观题以题间距分隔，填空及主观题在结束段落后按题型增加作答空间；题型标题使用内置 `\filbreak` 避免孤立在页尾。
- PDF 模板版本由 `v1` 提升到 `v2`。真实 XeLaTeX 双 PDF 编译、PDFBox 打开/渲染和第一页人工视觉检查通过。
