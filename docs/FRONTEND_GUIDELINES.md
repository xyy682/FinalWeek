# Frontend Guidelines — FinalWeek（求职版 MVP）

> 文档状态：Phase 1–16 已完成。文末“Phase 12–16 扩展界面”描述已交付的课程知识版本、全局任务、异步计划/答疑和模拟卷界面。
>
> 当前界面总览见 [`GPT_CONTEXT.md`](GPT_CONTEXT.md)。本文正文已按五个课程功能区和知识版本流程修正。

## Visual Direction

- 专注、清爽的浅色学习工具。
- 重点展示课程、资料状态、提纲和下一步操作，不堆插画或复杂动画。
- 桌面 Chrome/Edge 是首要演示环境；手机端保证基本浏览和操作。
- 前端用于完整展示后端链路，但不是本项目的主要技术卖点。

## Design Tokens

### Colors

| Token | Value | Usage |
|---|---:|---|
| `primary` | `#2563EB` | 主按钮、选中项、链接 |
| `primary-hover` | `#1D4ED8` | 主操作悬停 |
| `text` | `#111827` | 标题和正文 |
| `text-secondary` | `#4B5563` | 次要说明 |
| `border` | `#E5E7EB` | 边框和分隔线 |
| `background` | `#F8FAFC` | 页面背景 |
| `surface` | `#FFFFFF` | 卡片和弹窗 |
| `success` | `#15803D` | 成功、已完成 |
| `warning` | `#A16207` | 重试、解析警告 |
| `danger` | `#B91C1C` | 失败、删除 |

状态和重要度必须显示文字，不能只依赖颜色。

### Spacing and Shape

- 间距：4 / 8 / 12 / 16 / 24 / 32 / 48px。
- 控件圆角：8px；卡片和弹窗：12px。
- 页面内容最大宽度：1280px。
- 手机页面水平内边距：16px；桌面：24–32px。
- 普通卡片使用 1px 边框，不叠加重阴影。

### Typography

- 字体：`Inter, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`。
- 正文：14px/22px。
- 页面标题：28px/36px，600。
- 区块标题：20px/28px，600。
- 卡片标题：16px/24px，600。

## Responsive Rules

- `mobile`: `<768px`。
- `desktop`: `≥768px`。
- 桌面资料列表使用表格；手机改为卡片列表。
- 课程五个区域在手机使用横向可滚动标签。
- 树状提纲在手机保持折叠、来源查看和重要度调整。
- 首版不为 Safari/Firefox 建立正式测试矩阵，但不使用 Chromium 私有 API。

## Main Screens

### Login

- 单列邮箱和验证码表单。
- 显示验证码发送倒计时和 Mailpit 开发提示。
- 错误显示在对应字段下，提交失败不清空邮箱。
- Redis 不可用时明确显示“服务暂时不可用（503）”，不将其误报为验证码错误。

### Course List

- 空状态只有一个主操作“创建课程”。
- 课程卡片显示课程名、资料数量、最近解析状态和更新时间。
- 支持重命名和删除；删除使用确认弹窗。
- 删除时若课程仍有解析中/重试中任务，展示后端 409 提示并保留课程，待任务进入终态后允许再次删除。

### Course Navigation

- 课程标题下固定五个标签：资料、知识提纲、复习计划、课程问答、模拟卷。
- 每个标签有独立 URL，刷新后保留当前页面。
- 顶部显示正在执行的任务及当前阶段。

## Core Components

### Upload Panel

- 支持拖拽和文件选择。
- 显示文件名、大小、资料类型、重点说明、分片进度和操作。
- 上传中断后显示“继续上传”，并从后端读取已完成分片。
- 上传完成后切换为解析进度，显示阶段和百分比。
- `PENDING_PUBLISH` 显示“待投递”，`PUBLISH_FAILED` 显示“投递失败”及安全错误摘要并提供“重新投递”；若原因为 `AI_RATE_LIMITED`，明确提示稍后再试。解析失败显示“重试/删除”。
- 解析失败后的“重试”复用原任务和进度卡；前端不得创建第二张并行任务卡，手动重试轮次可作为辅助信息展示。
- 已解析成功的资料不显示单独删除入口；待投递、投递失败、排队、失败或已取消资料可按后端规则删除，排队资料由后端先原子取消。处理中/重试中暂不显示删除入口。成功资料只随整门课程删除。
- 不把上传进度和解析进度合并成一条含义不清的进度条。

### Task Status

- 状态文案：待投递、投递失败、排队中、解析中、重试中、解析成功、解析失败、已取消。
- 长任务使用持久任务卡，不只使用 toast 或无限转圈。
- SSE 断线时显示“正在重新连接”，同时保留最后状态。
- 失败卡片显示错误阶段、错误摘要和请求 ID。

### Outline Tree

- 默认展开前两层。
- 节点展示名称、重要度和来源数量。
- 重要度通过下拉选择高/中/低，修改后立即保存。
- 点击来源打开侧栏：文件名、页码/幻灯片/段落/时间点和原文片段。
- PDF/PPTX 来源通过后端预览接口打开归一化 PDF 并定位页码；MP3/MP4 来源按时间点设置播放器 `currentTime`，播放请求支持 Range。预览 URL 过期时重新请求，不缓存为永久链接。
- 首版不提供拖拽、增删节点、重命名或结构合并。
- 提纲由资料页“资料已上传完毕”确认知识版本后自动生成；没有新增成功资料时不提供手动重新生成。失败任务提供针对原知识版本的重试入口。
- 本课程已有活动提纲任务时禁用重复生成并继续展示该任务进度；刷新后从后端恢复现有活动任务。

### Study Plan

- 表单字段：考试日期、每日可用分钟数、整体掌握程度、目标成绩。
- 结果按日期分组展示任务。
- 每项包含知识点、预计用时和完成复选框。
- 只提供完成/撤销完成；不提供拖拽、跳过、重排和差异预览。
- 再次生成前提示覆盖。
- 生成操作返回后台任务：每次用户确认生成时创建请求幂等键，提交期间禁用重复提交；受理后允许离页，并由全局任务抽屉、SSE 和计划 REST 恢复终态。
- 计划生成触发 429 时显示稍后重试，不自动更换幂等键或无限重试。

### Course Chat

- 每门课程一条连续历史。
- 输入仅支持文字。
- 回答结构固定为：回答正文、课程资料来源、通用知识补充（可选）。
- 引用按钮显示文件名和位置，点击打开预览。
- 发送失败保留用户问题并允许重试。
- 问答提交后立即在历史显示 `PENDING` 消息；允许离页，返回页面时刷新历史。失败保留原问题并按原消息 ID 重试，避免重复消息；不展示 token 流式文本。
- 不提供会话列表、图片输入和复杂长期记忆设置。

## Forms and Feedback

- 所有字段有可见标签；必填项有明确标识。
- 客户端校验用于即时反馈，服务端仍需重复校验。
- 提交中禁止重复提交，但不清空输入。
- 删除、覆盖提纲、覆盖计划必须二次确认。
- 429 显示“请求过于频繁，请稍后再试”，不得自动无限重试。
- 任一已认证接口返回 503 时显示全局“服务暂时不可用”，停止自动重试；静态落地页仍可浏览。
- 错误响应展示稳定错误码或请求 ID，方便面试演示日志排查。

## Basic Accessibility

- 按钮、输入框和链接可用键盘访问。
- 焦点样式可见。
- 图标按钮有文字标签或 `aria-label`。
- 表单错误与字段关联。
- 文字和背景保持基本可读对比度。
- 首版不以正式 WCAG 2.2 AA 审计作为完成条件。

## Component Rules

- 业务组件使用 PascalCase，例如 `MaterialUploadPanel`、`TaskStatusCard`、`OutlineTree`。
- 使用 Element Plus 和统一设计令牌，不引入第二套 UI 库。
- 组件通过 typed props/emits 与 API service 交互，不直接拼接任意后端地址。
- API 类型集中管理；不得使用大面积 `any`。
- Markdown 必须清洗，不渲染模型返回的原始 HTML。

## Do

- 把任务阶段、失败原因和恢复操作展示清楚。
- 把来源定位作为提纲和问答的核心界面元素。
- 为覆盖和删除操作提供明确确认。
- 在桌面演示环境优先保证流程顺畅。

## Don't

- 不加入深色模式、复杂动画、思维导图或游戏化系统。
- 不在手机端复制复杂桌面表格。
- 不把通用知识伪装成课程资料。
- 不静默覆盖提纲或计划。
- 不为求职演示引入复杂前端架构。

## Phase 12–16 扩展界面（已实现）

### Course Navigation and Unlocking

- 课程标题下当前固定五个标签：资料、知识提纲、复习计划、课程问答、模拟卷；每个标签有独立 URL，手机端继续横向滚动。
- 标签始终可见。无成功资料时答疑页显示空状态和上传引导；无已发布提纲时计划与模拟卷页展示锁定原因并链接回资料页。
- 新资料已解析但尚未确认进入新版提纲时，计划和模拟卷页显示“仍使用上一课程知识版本”；答疑不显示此限制，因为它立即使用全部成功资料。

### Material Finalization

- 资料页增加主操作“资料已上传完毕”。存在上传中、待投递、排队、处理或重试资料时按钮禁用，并展示尚未结束数量。
- 没有成功资料时不能确认。存在失败或取消资料时，确认弹窗列出将被忽略的文件，并要求用户明确继续。
- 确认成功后显示知识版本生成状态并允许离开。提纲失败时提供“重试本次提纲”，不要求再次点击上传完毕。
- 没有新增成功资料时不显示或禁用重复确认；提纲页取消无新增资料条件下的“重新生成”。
- 当前提纲仍支持来源查看和人工重要度调整；新版本发布后说明旧人工重要度不会继承。

### Global Task Drawer

- 所有登录后页面的 `AppHeader` 增加任务图标、可访问名称和活动数量徽标；点击打开右侧抽屉。
- 抽屉只展示进行中的资料解析、提纲、复习计划和模拟卷任务，按最近更新时间排序；每项显示课程名、任务类型、中文状态、阶段、进度和跳转操作。
- 排队任务显示取消按钮；处理、重试和文件生成中的任务仅可查看。取消冲突后立即刷新服务端状态。
- SSE 只承担在线通知。完成或失败时显示一次全局提示并从抽屉移除；点击提示跳回对应业务页。
- 断线重连先请求活动任务列表再订阅；离线期间终态不补发通知，抽屉不建设终态历史或分页。

### Asynchronous Study Plan

- 计划表单字段、分组结果和完成复选框保持现状；提交后改为后台任务，不显示会阻止导航的长时间加载遮罩。
- 提交成功后表单区域显示任务摘要，当前计划继续可见。新计划成功才替换旧计划，失败提示原因并保留旧计划。
- 当前计划的知识版本落后时显示非阻断警告；任务仍可完成或撤销。
- 同一幂等请求不得因刷新或重复点击创建第二个任务；提纲变化导致失败时引导基于新版重新生成。

### Background Course Chat

- 发送问题后立即在历史中显示 `PENDING` 用户消息；用户可离开页面，不能把本地请求取消误写成服务端取消。
- 答疑不显示在任务抽屉。在线完成或失败时使用轻量全局提示；返回聊天页后从历史接口同步最终状态。
- 失败问题保留原文和重试入口；重试继续复用原消息 ID，禁止复制出第二条用户消息。

### Mock Exam Page

- 路由为 `/courses/:id/mock-exams`，页面采用“同页生成表单 + 下方分页历史”。提交表单和历史刷新互不阻塞。
- 表单包含：可选名称、整课/知识点范围、八类题型选择及逐题型题数、自动/自定义分值、可选总分、可选建议时长、默认开启的通用知识补题开关、最多 2000 字补充说明。
- 题型至少选择一种；选中后题数必填且为正整数，总计 1–50。取消题型时清除该题型数量和自定义分值，提交前明确展示总题数。
- 范围默认整课。选择知识点时复用可折叠提纲树；父节点选中完整子树，允许展开后取消部分子节点。无当前提纲时表单锁定。
- 分值模式默认系统分配。自定义模式为每个已选题型填写正整数单题分值；实时显示汇总且不得超过 1000。总分填写后必须与汇总一致。
- 总分为空时卷首不显示总分，但表单仍可展示系统/自定义汇总提示；建议时长为空时卷首不显示时长，填写范围为 1–300 分钟。
- 不提供难度下拉框。难度、语言、风格、重点和权重写入补充说明，并提示结构化字段及能力边界优先。
- 通用知识开关说明“仅在课程资料不足时使用模型内置知识，不联网；参考答案会标记相关题目”。关闭后提示资料不足可能导致生成失败。
- 同课程已有活动出卷任务时禁用再次提交；其他课程不受影响。提交成功后允许任意导航。

### Mock Exam History

- 历史按创建时间倒序分页并通过 URL 查询参数保存页码。默认行/卡片只显示名称、状态、生成时间和操作。
- 成功记录显示“预览试卷、下载试卷、预览参考答案、下载参考答案、删除”；预览在新标签页打开短时授权 PDF。
- 失败和取消记录显示“修改后重试、删除”；重试把原参数回填表单，提交后创建新记录并显示与原记录的关联。
- 运行中记录显示关键阶段与进度；只有排队状态提供取消，运行中不提供删除。
- 有失败原因、课程外补题、范围未完全覆盖或历史近似题警告时显示醒目标记，点击在记录内展开；正常记录保持精简。
- 删除使用二次确认。成功响应后记录立即从列表移除，不展示后台对象清理任务，也不提供回收站。
- 自动记录名可含生成时间；未自定义时 PDF 标题只显示“课程名模拟卷”。下载文件名使用“试卷名_生成时间_试卷/参考答案.pdf”。

### PDF Expectations

- 预览依赖浏览器原生 PDF 查看器，不在应用内嵌复杂阅读器。
- 试卷和参考答案 PDF 不显示平台课程版本、生成日期或“AI 生成”标识；通用知识题只在参考答案正文中标记。
- 首版不提供在线答题、评分、倒计时、错题本、分享、在线编辑或独立答题纸入口。

### Current Accessibility and Responsive Rules

- 任务图标、抽屉、题型选择、知识点树、警告展开和 PDF 操作均支持键盘访问、可见焦点和屏幕阅读器名称。
- 手机端表单纵向排列，历史使用卡片；任务抽屉占满可用宽度。不得把八类题型和自定义分值压缩成不可横向阅读的桌面表格。
- 所有任务、知识版本、模拟卷和消息状态必须显示文字，不得只依赖颜色、图标或进度条。
